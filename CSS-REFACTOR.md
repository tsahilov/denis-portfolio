## Что удалено и объединено

Удаление основано на проверке всего index.html, media.js и CSSOM страницы. CSS Coverage не использовался как основание для удаления. media.js не создаёт элементы/классы для удаляемых компонентов; он меняет свойства видео и data-атрибуты. Состояния :hover, псевдоэлементы опыта и скрываемые на мобильных элементы проверены отдельно.

Неиспользуемые блоки: .dark, figure/figcaption, aside, .images-sequence и вложенные правила, .columns, .note, .promo-link (включая .sleeping/:hover), .projects-grid, .project и .project--square, h1 span, .work-gallery--split-big и --split-reverse. Удалены неиспользуемые --icon-* и --surface-color-RGB, закомментированные эксперименты и лишние объявления начальных значений CSS.

Правило .work-gallery--giga-sochi > video:last-child не совпадает ни с одним видео: за последним video в HTML стоит noscript. Правило удалено как неработающее. Предполагаемое кадрирование «90% center» не включалось заново, поскольку это изменило бы текущую композицию. Если оно было задумано автором, это отдельная визуальная правка.

Повторы объединены:

- Общие колонки галерей: grid-template-columns: var(--gallery-columns, 1fr), пропорции — в конкретном модификаторе. На мобильных одна общая колонка; карусели переопределяют её своим grid-auto-flow.
- Единый --gallery-gap для внешних и вложенных сеток; общий стиль изображений/видео сохраняет размеры и скругления.
- Общее заполнение видео обеих строк Sochi и его мобильный режим contain.
- Общие свойства .promo-main/.promo-thumb и вложенных сеток DDD; удалены повторные width/display/height, уже заданные основой.
- Повторные мобильные aspect-ratio/object-fit B2B, одинаковые с десктопным значением; лишние grid-template-columns/grid-auto-flow у KV-карусели, уже заданные общей каруселью.
- После удаления повторного цвета .profile-links a ссылки используют общий a:hover; результат наведения сохранён и проверен.

HTML, media.js, шрифты, изображения, видео и постеры в этом PR не изменены. На сайт не добавлены библиотеки, фреймворки или сборка. tools/css-audit.cjs использует только локальные инструменты проверки, в сайт он не подключён.

## Проверка дизайна и поведения

Сравнение выполнено с CSS актуального main на 390, 768, 1440 и 1920 px, высота 900, DPR 1, Chrome headless.

- Проверены все 11 проектов, все 43 изображения и 15 видео. Неразрешённых/сломанных изображений нет.
- Для 248 элементов сравнивались все вычисленные обычные свойства CSS, размеры/позиции, ::before и ::after. Пользовательские --переменные намеренно исключены из сравнения: их организация менялась. Различий обычных свойств и геометрии — 0 на каждой ширине.
- Проверены состояния наведения ссылок, максимальная прокрутка, итоговые scrollLeft и scroll-snap трёх галерей-каруселей и шкалы опыта; значения совпали с базой. При 390 px все четыре области действительно прокручиваются.
- Сделано 95 пар снимков всей страницы и каруселей после прокрутки. Видео для этого сравнения фиксировались на своих постерах; настоящая загрузка и воспроизведение проверены отдельным проходом.
- На 1440 и 1920 px все снимки совпали пиксель в пиксель. На 390/768 px есть небольшие различия растеризации картинок Chrome при повторном применении CSS; геометрия и вычисленные стили совпали. Минимальная SSIM: 0,99960 на 390 и 0,99636 на 768 (1 — полное совпадение). Проверены сравнительные снимки с наибольшим расхождением: композиция и контент сохранены.
- Все 15 MP4 реально запускались в видимости и приостанавливались вне экрана на каждой из четырёх ширин: 60 проверок воспроизведения. Controls при автозапуске выключены. На первом экране активных video[src] нет.
- Существующий performance-audit.cjs --checks дополнительно проверяет reduced-motion, Save-Data, отсутствие IntersectionObserver/JavaScript, ожидающий play(), запрет autoplay, ручной запуск и симуляцию скрытия страницы.
- Ошибок JavaScript, горизонтального переполнения документа и проблем git diff --check не найдено.

Ограничения: это Chrome на компьютере, а не реальный Safari/iPhone. Псевдоклассы проверены в доступных состояниях, а не всеми возможными сочетаниями будущего контента. Полное совпадение текущей страницы не гарантирует дизайн для новых классов/проектов, которые появятся позже.

## Проблемы вне CSS

Главный резерв — медиаданные. 15 MP4 суммарно весят 202,42 МБ; candinsky-20.mp4 — 61,83 МБ и 4636×4636. Некоторые изображения WebP весят 2–3,3 МБ. Для большинства нет srcset с подходящей мобильной шириной. Эти файлы на данном этапе сохранены.

Native loading=lazy заранее загружает изображения вблизи экрана; даже после CSS-рефакторинга первые секунды могут быть заняты крупными WebP. Пауза видео вне экрана сохраняет CPU, но не гарантирует отмену уже начатой загрузки и освобождение буфера. В промо-сетке несколько видимых видео могут декодироваться одновременно. Для b2b-30.mp4 moov расположен после mdat — перенос в начало должен быть отдельной операцией с медиа.

Следующий этап: мобильные копии изображений/видео, адаптивные источники и проверка на реальных телефонах. Подробные исходные рекомендации перекодирования уже находятся в PERFORMANCE.md. За счёт дальнейшего сокращения нескольких килобайт CSS такой эффект получить нельзя.

## Как повторить и откатить

Опциональные инструменты разработчика — Playwright, sharp и установленный Chrome; они не нужны на хостинге и не добавлены в зависимости сайта. Можно указать PLAYWRIGHT_MODULE/SHARP_MODULE/CHROME_PATH для уже установленных инструментов.

```sh
node tools/css-audit.cjs a24caa5
node tools/css-audit.cjs a24caa5 --media-only
node tools/performance-audit.cjs css-refactor --checks
```

Первый запуск делает снимки и замеры, второй — отдельный проход всех видео. Результаты пишутся в игнорируемую .performance-results/. Снимки используют фиксированные постеры, ручную загрузку всех изображений и прогрев отрисовки только внутри теста. Реальная страница продолжает загружаться лениво. SSIM >= 0,995 допускает небольшую погрешность растеризации при одновременном строгом совпадении вычисленных стилей и геометрии. Полный тест занимает несколько минут.

Производственный рефакторинг — отдельный коммит ac2ba71. Для отката достаточно вернуть style.css из a24caa5 либо сделать git revert ac2ba71. Изменений в main и деплоя из этой ветки не выполнялось.
